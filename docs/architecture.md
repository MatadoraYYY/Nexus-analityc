# Архитектура

## Компоненты

1. `generator.py` создаёт детерминированные синтетические сущности.
2. `quality.py` проверяет схему, ключи, связи, перечисления, даты и диапазоны.
3. `metrics.py` и `statistics.py` содержат переиспользуемую бизнес-логику.
4. `pipeline.py` создаёт версионированные агрегированные витрины.
5. `site` отображает витрины; расчёты метрик в браузере запрещены.

## Заменяемость

CSV можно заменить на Parquet или базу данных через адаптер чтения, не меняя функций метрик. Статические JSON можно заменить серверным API при появлении авторизации и оперативных данных; контракт представления сохраняется.

## Надёжность

В production нет постоянно работающего процесса и изменяемого хранилища. Обновление — атомарная публикация проверенного статического артефакта через CI/CD; предыдущая версия остаётся доступной до успешного размещения новой.
