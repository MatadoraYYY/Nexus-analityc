# Документация статического API

Базовый путь: `/api/v1`. Метод всех ресурсов — `GET`, формат — JSON, код успеха — 200. API доступно для чтения с того же origin; параметры и операции записи отсутствуют.

| Ресурс | Русское назначение | Ответ и бизнес-смысл |
|---|---|---|
| `/health.json` | Проверка доступности | Статус, версия приложения и тип данных. |
| `/overview.json` | Обзор продукта | Активность, удержание, выручка, версии и аналитические сигналы. |
| `/acquisition.json` | Каналы привлечения | Пользователи, платящие и конверсия по каналу. |
| `/funnel.json` | Воронка активации | Число пользователей, конверсия и потери каждого этапа. |
| `/features.json` | Использование функций | Охват функций активными пользователями. |
| `/experiment.json` | Результат эксперимента | Размеры групп, конверсии, прирост, интервал, p-значение и решение. |
| `/quality.json` | Качество данных | Критичность, результат и пояснение каждой проверки. |

Пример: `GET /api/v1/health.json`. Ответ: `{"status":"работает","version":"1.0.0","dataset":"синтетический"}`. Ошибка 404 означает неизвестный ресурс; интерфейс показывает безопасное сообщение без внутренних путей и трассировки.
