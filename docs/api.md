# Документация статического API

Базовый путь: `/api/v1`. Метод всех ресурсов — `GET`, формат — JSON, код успеха — 200. API доступен только для чтения с того же источника; параметры и операции записи отсутствуют. Все описания и пользовательские сообщения русскоязычные, технические JSON-поля сохранены на английском для переносимости.

| Ресурс | Назначение | Ответ и бизнес-смысл |
|---|---|---|
| `/health.json` | Проверка доступности | Статус, версия приложения и тип данных. |
| `/overview.json` | Обзор продукта | DAU, WAU, MAU, вовлечённость, удержание, версии и аналитические сигналы. |
| `/acquisition.json` | Каналы привлечения | Пользователи, платящие, конверсия, расходы и CAC по каналу. |
| `/funnel.json` | Воронка активации | Пользователи, конверсия и потери каждого этапа. |
| `/cohorts.json` | Когортное удержание | Размер месячной когорты и D1/D7/D14/D30. |
| `/revenue.json` | Выручка | Динамика выручки, MRR, ARPU, ARPPU, отток, CAC, LTV и LTV/CAC. |
| `/features.json` | Использование функций | Охват функций среди MAU. |
| `/experiment.json` | Результат эксперимента | Группы, конверсии, прирост, 95% интервал, p-значение и решение. |
| `/quality.json` | Качество данных | Критичность, результат и безопасное пояснение каждой проверки. |

## Пример

`GET /api/v1/health.json`

```json
{"status":"работает","version":"1.0.0","dataset":"синтетический"}
```

Ошибка 404 означает неизвестный ресурс. Пользователь получает русскоязычную страницу без трассировки, внутренних путей и инфраструктурных деталей.
