# Происхождение данных и метрик

| Метрика/витрина | Исходные таблицы | Преобразование | API | Раздел панели |
|---|---|---|---|---|
| DAU/WAU/MAU, активация, удержание | `users`, `events` | единое определение активности и календарные окна | `overview.json` | Обзор, Удержание |
| Каналы и CAC | `users`, `payments`, `marketing_spend` | объединение по пользователю и каналу | `acquisition.json` | Привлечение |
| Воронка | `users`, `events` | упорядоченная последовательность за 7 дней | `funnel.json` | Воронка |
| Когорты | `users`, `events` | месяц регистрации и точные дни D1/D7/D14/D30 | `cohorts.json` | Когорты |
| Выручка, MRR, ARPU, ARPPU, отток, LTV | `subscriptions`, `payments`, `events` | финансовые правила версии 1.0.0 | `revenue.json` | Выручка |
| Использование функций | `events` | уникальные пользователи функции в окне MAU | `features.json` | Функции |
| A/B-эксперимент | `experiment_assignments`, `events` | z-тест двух долей, 95% интервал | `experiment.json` | Эксперименты |
| Качество | все CSV | схема, ключи, NULL, связи, перечисления, даты, диапазоны | `quality.json` | Качество данных |

Полная цепочка: детерминированный генератор → CSV версии 1.0.0 → критические проверки → Python/SQL-аналитика → агрегированные JSON-витрины API v1 → русскоязычная аналитическая панель.
