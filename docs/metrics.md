# Словарь метрик 1.0.0

**Активный пользователь** — уникальный пользователь, совершивший `project_created`, `task_created` или `meaningful_action`. Одно определение применяется во всех разделах.

**Активация** — создание проекта и затем задачи не позднее 7 календарных дней после регистрации. Повторы не увеличивают число активированных; задача до проекта не засчитывается.

| Метрика | Точное определение | Неприменимость |
|---|---|---|
| DAU | Уникальные активные за отчётный календарный день | Пустой набор даёт 0 пользователей. |
| WAU | Уникальные активные за 7 дней, включая отчётный | Пустой набор даёт 0 пользователей. |
| MAU | Уникальные активные за 30 дней, включая отчётный | Пустой набор даёт 0 пользователей. |
| Вовлечённость | `DAU / MAU × 100%` | При MAU = 0 возвращается `NULL`. |
| Активация | `Активированные / Зарегистрированные × 100%` | При отсутствии зарегистрированных — `NULL`. |
| Конверсия этапа | `Следующий этап / Предыдущий этап × 100%` | При нулевом предыдущем этапе — `NULL`. |
| Потери этапа | `(1 − Следующий этап / Предыдущий этап) × 100%` | При нулевом предыдущем этапе — `NULL`. |
| D1/D7/D14/D30 | Активные точно в день N / пользователи подходящей когорты | Неполная когорта исключается; пустая даёт `NULL`. |
| MRR | Сумма `monthly_amount` активных на отчётную дату подписок | Нет активных подписок — 0. |
| ARPU | Чистая выручка / MAU | MAU = 0 — `NULL`. |
| ARPPU | Чистая выручка / уникальные платящие | Нет платящих — `NULL`. |
| Отток клиентов | Отменённые в отчётном месяце / клиенты на начало месяца × 100% | Нет клиентов на начало — `NULL`. |
| CAC | Маркетинговые расходы / новые платящие | Нет новых платящих — `NULL`. |
| Модельный LTV | `ARPU × 0,82 / месячный отток` | Нулевой/отсутствующий отток — `NULL`. |
| LTV/CAC | `LTV / CAC` | Нулевой/отсутствующий CAC — `NULL`. |
| Использование функции | Пользователи функции за 30 дней / MAU × 100% | MAU = 0 — `NULL`. |

## Эксперимент

Используется двусторонний z-тест независимых долей с объединённой оценкой дисперсии для p-значения и необъединённой — для 95% доверительного интервала разности. Абсолютный прирост равен разности долей, относительный — разности, делённой на контрольную долю. Если контрольная конверсия равна нулю, относительный прирост равен `NULL`.

Для нескольких сравнений реализована процедура Benjamini–Hochberg, контролирующая ожидаемую долю ложных открытий. Наблюдаемая связь не доказывает причинно-следственную связь; причинный вывод допустим только при корректной случайной рандомизации и отсутствии нарушений эксперимента.
