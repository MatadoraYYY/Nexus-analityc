# Словарь метрик

Версия определений: **1.0.0**. Активный пользователь совершил `project_created`, `task_created` или `meaningful_action`; регистрация и просмотр не считаются активностью.

| Метрика | Определение |
|---|---|
| DAU | Уникальные активные пользователи за календарный день. |
| WAU | Уникальные активные пользователи за последние 7 дней, включая отчётный. |
| MAU | Уникальные активные пользователи за последние 30 дней, включая отчётный. |
| Вовлечённость | `DAU / MAU × 100%`. |
| Коэффициент активации | Активированные / зарегистрированные × 100%; активация — проект, затем задача в течение 7 дней. |
| Коэффициент конверсии | Пользователи следующего этапа / пользователи предыдущего × 100%. |
| Потери | `1 − следующий этап / предыдущий этап`. |
| D1/D7/D14/D30 | Активные ровно в день N после регистрации / подходящая когорта × 100%. |
| Валовая выручка | Сумма успешных платежей до возвратов. |
| Чистая выручка | Валовая выручка минус возвраты. |
| MRR | Сумма месячных сумм активных подписок на отчётную дату. |
| ARPU | Чистая выручка / активные клиенты. |
| ARPPU | Чистая выручка / платящие клиенты. |
| Отток клиентов | Отменённые подписки / подписки на начало периода × 100%. |
| CAC | Расходы на продажи и маркетинг / новые платящие клиенты. |
| Модельный LTV | `ARPU × валовая маржа / месячный отток`; при нулевом оттоке — `NULL`. |
| LTV/CAC | `LTV / CAC`; при нулевом CAC — `NULL`. |
| Использование функции | Уникальные пользователи функции / MAU × 100%. |
| Абсолютный прирост | Конверсия тестовой группы минус конверсия контрольной. |
| Относительный прирост | Абсолютный прирост / конверсия контрольной. |

Для A/B-теста применяется двусторонний z-тест разности независимых долей и непулированный 95% доверительный интервал разности. Множественные проверки корректируются методом Benjamini–Hochberg; причинные выводы допустимы только при корректной случайной рандомизации.
