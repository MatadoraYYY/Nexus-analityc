# Развёртывание

## Фактическое размещение версии 1.0.0

Версия 1.0.0 развёрнута как статические ресурсы Cloudflare Workers Static Assets по адресу:

- Production: `https://nexus-analityc.duonuts.workers.dev`

Конвейер собирает витрины `site/api/v1/*.json`, а интерфейс читает только агрегированные синтетические данные. Секреты, база данных и платные функции не используются; стоимость развёртывания остаётся 0 ₽.

## Рекомендуемый вариант

Cloudflare Pages: production-ветка `main`, команда сборки `python -m nexus.pipeline --generate --data data/processed --api site/api/v1`, каталог публикации `site`. Проект не требует базы, секретов, платного домена или постоянно работающего backend.

## GitHub Pages

В качестве полностью статической альтернативы можно публиковать каталог `site` через GitHub Actions. Перед включением проверьте актуальные ограничения аккаунта и репозитория. Не включайте billing, платный тариф или автоматический trial.

## Проверка production

1. Открыть главную и все 11 разделов на настольном и мобильном экране.
2. Проверить `/api/v1/health.json`, `/overview.json` и `/quality.json`.
3. Проверить 404, загрузку, пустые и ошибочные состояния.
4. Проверить CSP, `X-Frame-Options`, `nosniff` и отсутствие wildcard CORS.
5. Сопоставить версии production с последним проверенным коммитом.

Развёртывание считается проверенным только после выполнения этих действий на реальном URL.

## Проверенные ограничения на 14 сентября 2026 года

- Стандартные GitHub-hosted runners для публичных репозиториев остаются бесплатными; хранение артефактов и превышения лимитов отдельных планов требуют контроля.
- Cloudflare Pages Free допускает 500 сборок в месяц, одну одновременную сборку, до 20 000 файлов и до 25 MiB на файл. NEXUS существенно ниже этих границ.
- Render Static Sites можно размещать бесплатно, но они учитывают месячные лимиты трафика и минут сборки. Бесплатный Render Web Service засыпает после 15 минут простоя, поэтому для NEXUS не используется.

Актуальность тарифов следует повторно проверить непосредственно перед ручным подключением hosting. Платёжный метод не добавлять.
