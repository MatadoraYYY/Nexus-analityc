# Устранение неполадок

- **«Не удалось получить аналитические данные».** Запускайте сайт через HTTP-сервер, а не открывайте `index.html` как файл; повторно выполните конвейер.
- **Конвейер остановлен.** Откройте результаты `validate`; исправьте отсутствующие таблицы, дубликаты, связи, события, даты или суммы.
- **Метрика показывает «Нет данных».** Проверьте знаменатель и наличие подходящей когорты; система намеренно не заменяет отсутствие значения нулём.
- **Стили или JSON не обновились.** Очистите кэш браузера и убедитесь, что hosting опубликован из последнего коммита.
