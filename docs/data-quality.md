# Качество данных

## Критические проверки

Наличие таблиц, непустые и уникальные первичные ключи, внешние ключи, допустимые события, корректные ISO-даты, неотрицательные платежи и возвраты в пределах платежа. Любой сбой завершает конвейер с ненулевым кодом.

## Предупреждения

Пустой набор пользователей и необычно малый объём данных не подменяются ошибочными значениями. Предупреждение публикуется в витрине качества и требует аналитической интерпретации.
