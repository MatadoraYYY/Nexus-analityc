# NEXUS — платформа продуктовой аналитики

NEXUS — полностью русскоязычный, воспроизводимый portfolio-проект аналитики SaaS-продукта. Проект использует синтетические данные и бесплатную статическую инфраструктуру без обязательных расходов.

> Репозиторий инициализирован. Полная реализация, документация, тесты и CI/CD добавляются следующим коммитом.
