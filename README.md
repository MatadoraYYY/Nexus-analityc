# NEXUS — платформа продуктовой аналитики

[![Проверки](https://github.com/MatadoraYYY/Nexus-analityc/actions/workflows/ci.yml/badge.svg)](https://github.com/MatadoraYYY/Nexus-analityc/actions)

NEXUS — полностью русскоязычный, воспроизводимый portfolio-проект аналитики SaaS-продукта. Он демонстрирует цепочку «синтетические данные → качество → преобразования → метрики и статистика → статический API → аналитическая панель → тестирование → безопасное размещение».

> **Важно:** все данные и результаты синтетические. Они не описывают реальный бизнес и не содержат персональных данных.

## Возможности

- Активность за день, 7 и 30 дней, вовлечённость и активация.
- Воронка, удержание D1/D7/D14/D30, каналы, выручка, MRR, ARPU, ARPPU, отток, CAC, LTV.
- Использование функций и A/B-эксперимент с доверительным интервалом и p-значением.
- Критические и предупреждающие проверки качества данных.
- Статический версионированный API без постоянно работающего сервера и без обязательных расходов.
- Полностью русскоязычная адаптивная аналитическая панель.

## Быстрый запуск

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
python -m nexus.pipeline --generate --data data/processed --api site/api/v1
python -m http.server 8000 --directory site
```

Откройте `http://localhost:8000`. Для Windows команда активации: `.venv\Scripts\activate`.

## Проверки

```bash
ruff check .
pytest
python -m nexus.pipeline --generate --data data/processed --api site/api/v1
```

Критическая ошибка качества останавливает конвейер. Деление на ноль и неприменимые формулы возвращают `NULL`, а не бесконечность и не искусственный ноль.

## Архитектура

Статическая архитектура выбрана осознанно: расчёты выполняются в воспроизводимом Python-конвейере, а интерфейс читает готовые агрегированные JSON-витрины. Это разделяет бизнес-логику и представление, исключает «засыпающий» backend и подходит для бесплатного размещения.

```text
data/processed/*.csv
        ↓
проверки качества
        ↓
Python: метрики и статистика + sql/metrics.sql
        ↓
site/api/v1/*.json
        ↓
site/index.html + assets/app.js
        ↓
Cloudflare Pages или GitHub Pages
```

Подробности: [архитектура](docs/architecture.md), [внутреннее ТЗ](docs/specification.md), [происхождение данных](docs/lineage.md).

## Версии

Приложение, набор данных, конвейер и метрики имеют независимые версии `1.0.0`. Изменение определения метрики требует обновления словаря метрик, тестов и CHANGELOG.

## Стоимость

Локальная разработка, GitHub Actions для публичного репозитория и статическое размещение могут использоваться без обязательных платежей. Не подключайте платные тарифы, домены или функции без отдельного решения владельца.
